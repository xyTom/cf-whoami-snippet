# Contributing

Thanks for considering a contribution to Cloudflare WhoAmI.

This is intentionally a very small project, so contributions should keep the implementation simple and dependency-free unless there is a strong reason otherwise.

## Before opening a pull request

- Keep changes focused.
- Avoid adding dependencies for functionality that can be expressed clearly with the platform APIs.
- Preserve JSON field names unless a breaking change is justified.
- Do not add logging, analytics, tracking, or external network calls without explicit discussion.
- Update the README when behavior or returned fields change.

## Pull requests

A good pull request should explain:

1. What changed.
2. Why the change is useful.
3. Whether it changes the response schema or deployment behavior.
4. How the change was tested.

By submitting a contribution, you represent that you have the right to submit the work and agree that your contribution may be distributed under the repository's MIT License.
