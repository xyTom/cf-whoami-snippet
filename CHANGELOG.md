# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-09-09

### Added

- Initial public release.
- JSON response with IP, geo, ASN, edge, TLS, RTT, language, and user-agent metadata.
- Plain-text output via `?fmt=text` and `?fmt=plain`.
- OpenStreetMap link for approximate coordinates.
- `Cache-Control: no-store` and `X-Content-Type-Options: nosniff` response headers.
- Project provenance, contribution, security, and licensing documentation.
